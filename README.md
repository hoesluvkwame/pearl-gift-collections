## 🚀 How to Deploy on Vercel

### Method 1: Deploy with GitHub (Recommended & Permanent)
1. Push this project to your GitHub account:
   ```bash
   git add .
   git commit -m "Pearls Gift Collection - Vercel Ready"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/pearls-gift-collection.git
   git push -u origin main
   ```
2. Go to **[vercel.com](https://vercel.com)** and log in with GitHub.
3. Click **"Add New..."** > **"Project"**.
4. Import your **`pearls-gift-collection`** repository.
5. In **Environment Variables** (optional):
   - `ADMIN_PASSWORD`: Set your manager PIN (default is `pearls055`).
6. Click **"Deploy"**.
7. Vercel will give you a permanent URL like: `https://pearls-gift-collection.vercel.app`!

### Method 2: Deploy directly via Vercel CLI
From this project directory, run in your terminal:
```bash
npx vercel
```
Follow the interactive prompts:
- *Set up and deploy?* -> `y`
- *Which scope?* -> Select your personal Vercel account
- *Link to existing project?* -> `n`
- *What's your project's name?* -> `pearls-gift-collection`
- *In which directory is your code located?* -> `./`
- *Want to modify settings?* -> `n`

Once finished, deploy to production with:
```bash
npx vercel --prod
```
